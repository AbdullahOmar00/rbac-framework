# Least-Privilege Access Policy

**Version:** 1.0  
**Effective Date:** [Date]  
**Owner:** IT Security  

## Purpose

This policy ensures that every user account across enterprise systems is granted only the minimum level of access required to perform their job function. No more, no less.

## Scope

Applies to all employees, contractors, and vendor accounts across all enterprise IT systems.

## Policy

### 1. Default Access

All new accounts are created with the lowest access level (read-only or viewer). Elevated access requires a formal request with business justification and manager approval.

### 2. Access Request Process

1. User submits access request specifying: system, role requested, and business justification
2. User's direct manager approves or rejects
3. IT reviews against the role matrix for that system
4. If the requested role exceeds what is standard for the user's department, IT flags for additional review
5. Access is provisioned only after all approvals are documented

### 3. Admin Access

- Admin access is restricted to IT and Security personnel only
- Requires IT Manager approval
- Reviewed monthly (not quarterly like standard roles)
- Must be removed within 24 hours of role change or termination

### 4. Contractor and Vendor Access

- All external accounts must have an expiration date
- Maximum access duration: 90 days (renewable with re-approval)
- No admin access for external accounts under any circumstance
- Sponsor (internal employee) must be assigned for each external account

### 5. Access Reviews

- Quarterly reviews of all active accounts
- Dormant accounts (90+ days no login) are deactivated automatically
- Role mismatches are corrected within 5 business days of identification
- Review findings are documented and reported to management

### 6. Termination and Role Changes

- Access is revoked within 24 hours of termination
- Role changes trigger an access review: old access removed, new access granted per updated role
- IT receives automated notification from HR system on all terminations and transfers

## Enforcement

Violations of this policy may result in immediate access revocation and escalation to management. Repeated violations are reported in the quarterly risk summary.
